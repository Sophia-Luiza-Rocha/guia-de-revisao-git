# GitHub Flow
## Os seis passos
1. Crie uma branch a partir da `main` para trabalhar isoladamente.
2. Faça commits pequenos e claros com as mudanças.
3. Abra um Pull Request para propor a integração na `main`.
4. Peça revisão, converse sobre o diff e faça ajustes em novos commits.
5. Confira os testes e as verificações do repositório.
6. Depois da revisão e das verificações, faça o merge do Pull Request.
## Por que não editar direto na main?
Trabalhar em uma branch mantém a versão principal estável enquanto a mudança é preparada. O Pull Request deixa o histórico visível e oferece espaço para revisão, discussão e ajustes antes da integração.
## O que significam as cores do diff?
As linhas em vermelho indicam conteúdo removido ou substituído. As linhas em verde mostram o conteúdo adicionado. A comparação ajuda a conferir exatamente o que mudou.
