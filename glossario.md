# Glossário de versionamento
1. **Git** — Ferramenta de controle de versão que registra mudanças em arquivos e permite trabalhar em linhas paralelas.
2. **GitHub** — Serviço online que hospeda repositórios Git e oferece recursos para colaborar, revisar e discutir mudanças. Git é a ferramenta; GitHub é uma plataforma que usa Git.
3. **Repositório** — Projeto com seus arquivos e o histórico das alterações.
4. **Commit** — Registro de um conjunto de mudanças, acompanhado de uma mensagem que resume o que foi feito.
5. **Branch** — Linha de trabalho separada, usada para desenvolver mudanças sem alterar diretamente a linha principal.
6. **main** — Branch principal do repositório, onde ficam as mudanças integradas.
7. **Merge** — Ação de unir as mudanças de uma branch a outra.
8. **Pull Request** — Proposta para integrar uma branch à main, com espaço para revisão e discussão antes do merge.
